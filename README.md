# Видеоигры в данных, 1980–2015

Интерактивный дашборд к лабораторной работе № 3 «ИИ в визуализации данных».

## Что внутри

- `index.html` — страница дашборда;
- `assets/css/style.css` — оформление и адаптив;
- `assets/js/data.js` — агрегаты, подготовленные из CSV;
- `assets/js/main.js` — отрисовка SVG-графиков, фильтры, подсказки;
- `data/vgsales_clean.csv` — исходный очищенный датасет;
- `prepare_data.py` — скрипт подготовки агрегатов;
- `Отчет_Инфографика_ЛР3.pdf` — PDF-версия дашборда для сдачи.

Внешних библиотек нет: графики построены на SVG, CSS и JavaScript.

## Четыре графика

1. **Streamgraph** — как менялся состав продаж по жанрам с 1980 по 2015 год. Жанры подписаны прямо у лент.
2. **Sunburst** — из каких жанров и семейств платформ складывается рынок. Названия семейств — на самом кольце.
3. **Bubble chart** — какие платформы выпускали много игр, а какие много продавали.
4. **Heatmap** — когда каждая платформа была на пике.

Отдельных легенд у графиков нет. Дополнительно: топ-10 игр по выбранному региону, фильтры по региону и периоду, подсказки при наведении.

## Данные

Источник: открытый датасет **Video Game Sales** на Kaggle:

https://www.kaggle.com/datasets/gregorut/videogamesales

В работе используется очищенная версия `vgsales_clean.csv`.

Ограничения:

- продажи измеряются в **миллионах копий**, а не в деньгах;
- одна игра может встречаться несколько раз — по платформам;
- 2016 год исключён как неполный;
- удалены 4 записи, где год релиза раньше выхода платформы;
- исходные значения — оценки VGChartz, они могут отличаться от официальной отчётности.

Итоговый срез: **15 973 записи**, **8 745,2 млн копий**, **12 жанров**, **31 платформа**, 1980–2015.

## Локальный запуск

Из папки `dashboard`:

```bash
python3.11 -m http.server 8000
```

Откройте `http://127.0.0.1:8000/`.

## Публикация на GitHub Pages

1. Загрузите содержимое папки `dashboard` в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch → main → / (root)**.
4. Ссылка будет вида `https://USERNAME.github.io/REPOSITORY/`.

Файл `.nojekyll` уже добавлен.
